An AI-powered interactive photo booth designed for Saudi events and exhibitions.

The system allows visitors to upload or capture a photo, select an AI visual style, perform AI face swapping, enhance facial details, and receive a transformed image through an interactive Gradio kiosk interface.

Technologies: Python, PyTorch, Diffusers, Stable Diffusion XL, InsightFace, GFPGAN, CodeFormer, OpenCV, Gradio.

Use cases: Saudi events, exhibitions, entertainment experiences, brand activations, cultural events, Vision 2030 experiences, and interactive AI installations.
